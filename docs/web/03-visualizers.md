# 可视化设计（三个 WOW 效果 + 协作大厅）

完全排除折线图、表格等"数据化"设计，聚焦展示 Agent 团队的科学认知地图与逻辑推演过程。

---

## WOW 效果 1：三维太阳物理知识图谱（3D Evolving Concept Net）

### 定位

界面左侧悬浮的 3D 概念认知图谱，Librarian 检索所得概念的视觉具象化。

### 技术栈

- **`react-force-graph-3d`** — ThreeJS/WebGL + d3-force-3d 物理引擎
- **Motion** — 节点 hover 微动画
- **GSAP** — 连线粒子散开特效

### 数据来源

- Librarian agent 输出的候选假设 + 检索到的物理概念节点
- HelixDB 图谱数据（Paper / Hypothesis / Evidence / Critique 节点 + 关系边）

### 交互设计

| 事件                              | 效果                                                          |
| --------------------------------- | ------------------------------------------------------------- |
| Tournament 迭代开始               | 图谱淡入，节点按物理概念分类着色（磁场/热力学/波动/重联）     |
| Oracle/Explore 引入新物理参量约束 | 对应节点高亮，连线**实时重构**（d3-force 重新布局）           |
| 用户点击连线                      | 触发**粒子散开特效**（GSAP timeline），展现背后的物理机理卡片 |
| 用户点击节点                      | 展开节点的详细描述（Radix Popover）                           |
| 假设被淘汰                        | 对应分支节点变灰，连线淡出                                    |

### 布局

```
┌─────────────────────────────────┐
│                                 │
│      3D 力导向图谱              │
│      （悬浮，可拖拽旋转）       │
│                                 │
│   ●─────●                       │
│   │      \                      │
│   ●       ●─────●               │
│            \                    │
│             ●                   │
│                                 │
└─────────────────────────────────┘
  左侧 1/3 宽度，全高
```

## WOW 效果 2：Co-Scientist 智能体协作大厅 + 辩论剧场（Debate Theater）

### 定位

界面中央展示圆形"Sisyphus 智能体协作大厅"，6 个 agent Avatar 呈环形排列，实时展示"科学辩论与协作"过程。

### 技术栈

- **React Flow**（`@xyflow/react`）— 6 agent 头像作节点，消息流作边
- **GSAP** — 剧本式多元素同步动画（核心亮点）
- **React Bits** — Avatar 光环、能量场等视觉效果
- **Radix Tooltip** — agent 状态提示

### 节点设计

6 个 agent 作 React Flow 自定义节点，环形排列：

```
            Sisyphus（编排器，顶部）
           /        \
      Librarian    Prometheus
          |            |
       Looker       Oracle
           \        /
            Explore（底部）
```

每个节点显示：

- Agent 名称 + 角色
- 当前状态（idle / thinking / executing tool / waiting approval）
- 实时 token usage（圆形进度环）
- 最新输出摘要（hover 展开）

### 辩论剧场动画（GSAP timeline 剧本式）

| 场景                  | 动画序列                                                                  |
| --------------------- | ------------------------------------------------------------------------- |
| Oracle 抛出批判       | Oracle 节点闪红光 → 红色警告粒子沿边飞向被批判的假设节点 → 假设节点震动   |
| Sisyphus 响应         | Sisyphus 节点亮起 → 蓝色脉冲扩散到相关 agent → 边变粗表示消息流           |
| Librarian 生长 CoT 树 | Librarian 节点吐出绿色光线 → 光线分叉成树状 → 每个分叉点显示 CoT 步骤卡片 |
| 假设被淘汰            | 被淘汰节点枯萎动画 → 灰色粒子消散                                         |
| 假设获胜              | 获胜节点开花动画 → 金色光环扩散                                           |

### 消息流边

- React Flow 的 edge 实时显示 agent 间消息传递（脉冲粒子沿边流动）
- 边颜色区分消息类型：蓝色=正常协作、红色=批判、绿色=新假设、金色=审批通过

## WOW 效果 3：锦标赛假说演化谱系树（Tournament Evolution Tree）

### 定位

界面右侧展示"假说演化进化树"，Co-Scientist 多轮淘汰赛的可视化谱系。

### 技术栈

- **d3-hierarchy** — 树布局算法（cluster / tree）
- **自写 SVG** — 完全控制视觉
- **Motion** — 节点生长/枯萎动画
- **GSAP** — 开花/发光特效

### 数据来源

- 后端 `hypotheses` 表 + `mutations` 表 + `critiques` 表
- 每轮快照（SPEC §6 Tournament Evolution）

### 树结构

```
                    种子假设
                   /        \
            假设 A          假设 B
            /    \             |
      A-v1     A-v2         B-v1（被批判枯萎）
       |         |
   A-v1.1     A-v2.1（最终获胜 F1=0.91，开花发光）
   （枯萎）
```

- 根节点 = 用户输入的种子假设
- 每轮 Oracle 突变生成子节点
- 被 Oracle 证伪或 Explore 低分的分支**枯萎断裂**（灰棕色 + 断裂动画）
- 获胜并经用户微调的分支**开花/发光**（金色 + 花瓣粒子）

### 交互设计

| 事件         | 效果                                                                |
| ------------ | ------------------------------------------------------------------- |
| 新轮次开始   | 树整体震动，新分支从父节点生长出来（Motion spring）                 |
| 假设被批判   | 对应分支变灰，连线断裂动画，灰色粒子下落                            |
| 假设获胜     | 节点放大，金色光环 + 花瓣粒子绽放（GSAP）                           |
| 用户点击节点 | 展开假设详情（Radix Dialog）：物理公式、F1 分数、批判历史、证据链接 |
| Hover 分支   | 高亮整条演化路径                                                    |

### 布局

```
┌─────────────────────────┐
│                         │
│         🌸              │  ← 获胜假设（开花）
│        / \              │
│      🌿   💀            │  ← 存活 vs 枯萎
│      /     \            │
│    🌿       💀          │
│     |                   │
│    🌱                   │  ← 种子假设
│                         │
└─────────────────────────┘
  右侧 1/3 宽度，全高
```

## Sisyphus 协作大厅（React Flow 节点图）

### 定位

Run 主界面底部或独立 tab，展示 6 agent 的实时协作拓扑。

### 与辩论剧场的关系

- **辩论剧场**（WOW 效果 2）= 协作大厅的**电影模式**（剧本式动画，自动播放辩论过程）
- **协作大厅** = 协作大厅的**交互模式**（用户可拖拽节点、点击查看详情、手动触发 agent）

### 节点详情面板

点击任意 agent 节点，右侧滑出详情面板（Radix Sheet）：

- Agent 当前状态 + 正在执行的 tool
- 最近 10 条消息（折叠的 message parts）
- Token usage 统计（图表用 Motion 做的环形图，非传统折线图）
- 该 agent 的 Skills 列表
- 手动触发按钮（开发调试用）

### 视图切换

顶栏 tab 可切换：

- **全协作大厅模式**：底部 React Flow 放大占满，三个可视化缩成缩略图
- **全图谱模式**：3D 图谱放大
- **全树模式**：演化树放大
- **四视图均衡**（默认）：上图布局

### 响应式

- 桌面（>1280px）：四视图均衡
- 平板（768-1280px）：协作大厅折叠成底部抽屉，上三视图保留
- 手机（<768px）：只显示 Chat Thread，其他可视化 tab 切换

## 视觉风格

### 配色（深色科技风）

- 背景：深空蓝/黑（`#0a0e1a`）
- 主文字：柔白（`#e8eaf0`）
- 强调色：
  - Sisyphus：蓝（`#3b82f6`）
  - Librarian：绿（`#10b981`）
  - Looker：青（`#06b6d4`）
  - Explore：紫（`#8b5cf6`）
  - Oracle：红（`#ef4444`，批判时）
  - Prometheus：金（`#f59e0b`）
- 假设状态：存活=绿、枯萎=灰棕、获胜=金光

### React Bits 应用点

- **BlurText** — agent 名称的渐入动画
- **Particles** — 3D 图谱背景的星空粒子
- **AnimatedGradientText** — Run 标题、F1 分数高亮
- **GlowCard** — agent 节点卡片的发光边框
- **ShimmerButton** — 审批按钮的微光效果

### 字体

- 标题：等宽字体（JetBrains Mono / Fira Code）— 科技感
- 正文：无衬线（Inter）
- 物理公式：KaTeX 或 MathJax 渲染（假设详情里的物理过滤函数）
