# Open-Scientist 科学闭环架构图 V2 修订提示词

以 V1 架构图为唯一编辑对象，只修改最左侧输入区域，其他阶段、文字、配色、箭头、闭环和版式均保持不变。

输入区域标题改为“输入：现象 + 相关数据”，内部依次为：

1. “现象”——“现象描述 / 科学问题 / 研究对象”；
2. “相关数据”——“与现象直接相关的数据集合”；
3. “数据内容信息”——“类型 / 来源 / 变量 / 时空范围 / 格式”；
4. “数据引用与完整性”——“sourceId + URI + metadata + checksum”。

在输入区域底部以弱化文字注明：“观测、模拟、派生等仅作为数据类型信息”。不得再把多波段观测、数值模拟或派生数据绘制成与现象并列的顶层输入类别。

保持 16:9 白底、扁平矢量学术架构图风格。只允许修改输入区域，不新增图标、标签、水印或装饰，不重新设计其余布局。
