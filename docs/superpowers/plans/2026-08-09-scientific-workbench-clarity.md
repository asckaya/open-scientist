# 科学工作台展示收束计划

## 目标

把项目页收束为一个清晰的科学主工作区，并把右侧多轮对话改成受控的“运行控制台”抽屉：默认不抢占主内容，打开后仍能完成现象提交、实时运行、多轮查看、轮次/假设筛选和新一轮运行。

## 约束

- 保留现有 SSE、`WorkflowRuntimeProvider`、运行状态回调和 demo 数据，不改后端闭环逻辑。
- 保留四个科学视图和现有选择联动；只调整信息层级、可见性和响应式布局。
- 不覆盖共享工作区中的其他用户改动，不执行 reset、checkout 或清理无关文件。
- 以中文科学工作流为主，减少重复的产品宣传文案和英文装饰标签。

## 实施步骤

1. **建立新的页面层级**
   - 修改 `apps/web/src/app/projects/[project]/page.tsx`。
   - 将对话默认设为收起，顶部按钮改为带文字的“运行控制台”，并显示运行中/有结果等状态。
   - 桌面端使用窄抽屉，移动端使用覆盖式面板；打开和关闭不影响主工作区状态。
   - 保留视图切换、运行回调和四类可视化组件。

2. **压缩科学主工作区**
   - 修改 `apps/web/src/components/workbench/scientific-workbench.tsx`。
   - 将大段 intro、预览说明和交互提示合并为一条紧凑的工作区摘要。
   - 把“现象、闭环阶段、假设、证据、验证、结论”组织成单一纵向阅读顺序，保留科学结果内容。
   - 将“下一步验证”与结论放在主结果区，避免右侧再重复操作指导。

3. **收束多轮对话面板**
   - 修改 `apps/web/src/components/chat/chat-panel.tsx` 和 `apps/web/src/components/assistant-ui/thread.tsx`。
   - 顶部统一为“运行控制台”，保留新建运行、运行轮次和假设筛选，但降低装饰性标题和重复说明。
   - 空状态改为简短的当前现象/操作提示；示例改为折叠内容，避免与工作台重复。
   - 多轮消息保留滚动查看，输入区固定在底部，明确“提交现象 / 继续本轮”的动作。

4. **补齐布局样式**
   - 修改 `apps/web/src/app/globals.css`。
   - 增加工作区摘要、抽屉、遮罩、移动端覆盖面板和紧凑筛选器样式。
   - 限制面板宽度、间距和文本行长，避免大屏和窄屏出现横向挤压。

5. **验证与自反馈**
   - 运行 web typecheck、构建和现有测试。
   - 在 5173 上验证默认工作台、打开/关闭运行控制台、四个视图切换和移动端布局。
   - 检查浏览器控制台无新增错误；若发现层级或交互仍然拥挤，再做一轮小幅调整。

## 验收标准

- 默认进入项目页时，主视觉是科学工作区，不被多轮聊天挤压。
- 点击“运行控制台”后可以看到消息历史和输入区；运行过程中控制台不会被隐藏。
- 轮次/假设筛选、新建运行、消息回调和科学结果更新仍可用。
- 工作台不再同时出现三套重复的“如何开始”说明。
- 5173 页面、TypeScript、构建和现有测试均通过。
