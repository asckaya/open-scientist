# P2｜选题与科学问题

## 2.1 选题与动机（200 字以内）

日冕加热存在波动耗散、纳耀斑重联及二者耦合等竞争解释；单一强度曲线容易受通道响应、背景活动和事件选择影响，不能直接等同于机制证据。本项目以 AR11158 为发现事件、AR11429 为冻结参数留出事件，检验哪些观测可区分候选机制，并明确当前数据无法判定的边界。

## 2.2 科学问题精确表述

在已登记的两个活动区与一个同活动区背景窗口中，AIA 171/193 Å 的时序变化、AIA 94/131 Å 的间歇热增强及 HMI 视向磁场演化，是否满足波动耗散、低频纳耀斑重联或波动—重联耦合机制各自预注册的可观测预测？在背景对照、跨活动区留出检验和不确定度约束下，哪些证据可提升或降低各假设的可信度；若仍不能区分机制，最小的下一步数据或分析是什么？

本项目的目标不是同时证明所有机制，也不是强迫系统选出“唯一赢家”，而是完成以下闭环：

1. 从给定科学现象生成彼此可区分的候选假设；
2. 将每条假设拆成可检验预测与证伪条件；
3. 用论文、真实观测、确定性计算和反例分别约束预测；
4. 对证据独立性、数据谱系和不确定度做审计；
5. 输出“支持、反对、混合、未知或需要数据”的有边界结论；
6. 按信息增益和成本给出下一步验证计划。

# P3｜系统设计与方法

## 3.1 系统架构

![Open-Scientist 科学闭环架构](docs/figures/open-scientist-scientific-loop-architecture-v2.png){width=90%}

系统保留现有前端和总体工作流，后端按“输入现象 → 假设 → 预测 → 证据/反例 → 状态综合 → 验证任务 → 下一轮”循环。Qwen 负责受约束的科学语言推理；确定性处理器负责 FITS 质量控制、统计量和可复核出处；最终状态由程序化门槛而非模型自评决定。

## 3.3 关键设计决策与创新点

1. **模型证据与经验事实分层。** 论文摘要和 Qwen 评述只能形成理论背景或待检验预测；只有绑定真实数据、确定性处理版本、原始 SHA-256 和量化结果的记录才可进入经验门槛。
2. **预测级证据闭环。** 不只给整条假设打一个主观分数，而是逐条预测记录支持、反对、混合或未知，并检查所有关键预测是否被覆盖。
3. **按独立事件和原始数据谱系计数。** 同一事件、同一原始指纹的多次运行不重复增加支持强度，防止把记录条数冒充独立证据。
4. **反例优先和背景对照。** AR11158 同活动区背景用于检查非特异性变化，AR11429 作为冻结参数留出事件；不允许只展示最有利窗口。
5. **“科学状态”与“闭环状态”分离。** 系统可完成一轮完整推理并给出下一步计划，但若未满足支持门槛，结论仍为 `needs_data`，不把流程完成误写成机制已证实。
6. **按诊断缺口决定是否加数据。** 先用现有六个 AIA 波段和 HMI 完成可执行分析；只有某个高优先级预测因独立事件不足而阻塞时才补第三事件，光谱则作为机制判别所需的另一类数据，而非盲目扩大同类成像数据。
7. **可配置的强支持门槛。** 本提交拟采用：至少 3 个可审计支持记录、3 个独立事件、3 个独立原始谱系、2 个观测量族、2 个方法族、至少 1 个 holdout、关键预测全覆盖、量化区间与完整 provenance，且假设置信度不低于 0.60。任何一项不满足，系统都不能输出“强支持”。

**正式基线使用现有全部 7.374 GB，而不是只用 58.16 MB 缓存。** 一轮完整复现依次读取发现窗、背景窗和留出窗；预处理缓存约 58.16 MB，仅保存有损降采样 ROI 代理，用于减少重复 FITS 解码。原始 FITS 必须保留，因为 WCS 配准、环形态、传播速度、DEM、光谱和能量闭合不能由缓存恢复。

预处理流程为：校验 manifest 与 SHA-256 → 拒绝非零 `QUALITY` 帧 → 按曝光时间归一化 → 有限值掩膜 → 按预处理版本、目标尺寸和原始哈希确定性缓存 → 计算时序/峰值/相关与区间 → 记录原始数据谱系。当前每条流不超过 96 帧时使用全部登记帧，不做随机抽样。

**当前数据足以提交一个真实、可复现的 2B 闭环 Demo，但不足以声称任何机制已被证明。** 原因不是总 GB 过小，而是尚缺若干判别性分析和独立性条件：跨通道冷却时滞、事件目录/能量代理、完整 WCS 配准与传播诊断尚未全部执行；严格门槛还要求第三个独立事件；当前无 EIS/IRIS 光谱、Doppler 速度和非热线宽。

数据扩充采用条件式决策：

1. **现在不立即下载。** 先用现有 94/131/171/193/211/335 Å 与 HMI 完成冷却时滞、事件统计、WCS 审计和传播诊断。
2. **若仅被独立事件数阻塞，** 再增加一个预注册活动区的 94/131/171/193 Å + HMI 2 h 窗口，估算增加约 1.384 GB，总量约 8.758 GB，仍低于当前 9.3 GB 数据预算。
3. **若被机制不可辨识性阻塞，** 优先补与目标时段匹配的 Hinode/EIS 或 IRIS 光谱，而不是继续堆叠同类型 AIA 图像。光谱数据量和时间窗须先按共同覆盖情况核定，当前不编造 GB 数。
4. **停止条件。** 当高优先级假设的关键预测已获得所需独立事件、观测量族、方法族、holdout、区间和 provenance，或新增数据已不能改变假设排序时停止扩充。

## 5.2 证据链构建

### H1：波动耗散

1. 理论文献给出传播、阻尼、相位差、非热线宽和能流闭合等可检验预测，但不直接支持本事件。
2. AR11158 的确定性 AIA 时序处理检测到 171/193 Å 相关变化；最新本地运行报告约 1800 s 主周期、跨通道相关约 0.49。
3. 1800 s 不在本轮预注册的 2–10 min 范围内，因此该结果对 H1 的特定周期预测形成反对记录，而不是“检测到周期即支持波加热”。
4. 现有数据尚未完成沿环 WCS 配准、传播速度、横向位移和能流估计，关键预测为 `unknown`。
5. 当前结论：**H1 为候选但未获支持；已有一项定向反例，需先完成现有数据可做的传播诊断。**

### H2：低频纳耀斑重联

1. 文献将间歇高温发射、多通道冷却时延、发射量和事件统计列为候选诊断，同时明确这些特征不是纳耀斑的唯一指纹。
2. AR11158 的确定性处理检测到 94/131 Å 两个稳健热增强峰，热通道相对变异约 0.508，目标/背景变异比点估计约 3.23；原始文件、处理版本和区间可追溯。
3. AR11429 留出窗对“间歇热增强”这一原子预测产生同向经验记录，提供跨活动区可迁移性检查。
4. 这些记录只覆盖 H2 的第一条预测；未验证事件能量幂律、多通道冷却顺序、磁自由能积累或光谱高温成分，因此不能从“相容”跃迁到“机制证明”。
5. 当前结论：**H2 是优先验证假设，有局部、非唯一的跨事件相容证据，但置信度 0.56、预测覆盖和方法独立性均未过强支持门槛。**

### H3：波动—重联耦合

1. H3 预言波动相位/振幅与热增强之间存在可复现关系，并要求排除共同驱动或视线叠加。
2. 当前 AIA 数据同时出现时序变化和热通道峰，但尚未以固定参数测量事件前后相位、传播和磁场三元关系。
3. “两个现象同时出现”只是生成 H3 的动机，不构成耦合证据。
4. 当前结论：**H3 仍为 `unknown/candidate`，须通过预注册时延、条件事件叠加和留出事件复现来检验。**

## 6.2 失败或局限案例

一次目标/背景变异比的 bootstrap 计算遇到接近零的分母，产生无物理意义的巨大上界。若只挑选点估计，这一结果很容易被包装成“目标区显著强于背景”。后端现在保留点估计、触发条件和局限，拒绝发布病态区间，也不允许该记录进入严格支持门槛。这说明系统能识别统计失败并降低结论强度。

1. 最新真实 Qwen 结果是在新结构化验证契约完全接入前生成，需冻结代码后重跑；
